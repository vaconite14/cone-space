# Klien / pekerjaan Cone Space

Satu folder per klien atau proyek: `office/klien/<nama-klien>/`.
- `CLAUDE.md`: aturan khusus klien (gaya bahasa, format output, larangan). Aturan di sini menang atas aturan umum kantor,
  kecuali batasan keamanan di `CLAUDE.md` utama.
- `docs/`: pengetahuan klien (profil brand, produk, standar konten) dan `docs/catatan-berjalan.md` untuk keputusan baru dari Val.
- Folder hasil kerja (misal `konten/`, `riset/`, `jadwal/`) sesuai kebutuhan.

Setelah menambah klien, daftarkan di tabel "Pekerjaan Val" di `CLAUDE.md` utama.
